# Caixun Sgamer (device cottongreen, product Caixun_4K_RATV3, made by Expressluck), Google TV on Android 14,
# firmware UKRC.260302.020. Realtek RTD2885N SoC, RTD6748 platform, about 1.7 GB RAM, Latin America.
# Same platform as examples/kalley-r10g/ and examples/prismplus-q65-ultra-r10g/; same ODM as examples/aipro2k/.
#
# Apply:   TV_HOST=<tv ip> tools/disable.sh examples/caixun-4k-ratv3/debloat.txt
# Undo:    TV_HOST=<tv ip> tools/restore.sh examples/caixun-4k-ratv3/debloat.txt com.google.android.apps.tv.launcherx
# Everything is DISABLED, not uninstalled. Comment out any line you want to keep.
#
# Stock launcher: com.google.android.apps.tv.launcherx (pass it to restore.sh).
# Connection: this set came up on Wireless debugging (_adb-tls-connect._tcp). Run `adb tcpip 5555` first,
# since tools/tv.py talks to port 5555, and close the port again when done.
# Language: the set runs in es-ES (persist.sys.locale); nothing here touches it, and the launcher follows it.
# Inputs: com.android.tv.action.VIEW_INPUTS resolves to com.google.android.tv.inputplayer/.switcher.SelectInputActivity.
# Input button: the "Smart GTV-R Remote" sends KEYCODE_TV_INPUT (HID usage 0x0C01BB), not KEYCODE_TV, so the
# launcher's InputKeyService does not help; leave it off (-InputKeyService), since while it filters keys a held
# key no longer repeats (held volume moved one step). com.realtek.tv answers the button by broadcasting to
# launcherx's GlobalButtonLaunch_Receiver, so with launcherx disabled the button does nothing: use Inputs on Home.
# Re-enabling launcherx brings the button back but takes Home over again (priority 2 against 0), and shell
# cannot disable only its HomeActivity.
#
# Already disabled from the factory (do not re-enable them on restore): com.google.android.play.games,
# com.google.android.youtube.tvmusic.
#
# Built on 2026-10-24 from the Kalley R10G list and the packages on this set. NOT YET TESTED on the TV.
